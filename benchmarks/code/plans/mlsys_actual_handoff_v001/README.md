# Automatic actual-model continuation on the current v5e

The original frozen main campaign skipped model jobs after an ensurepip failure.
Its original plan releases the allocation after the shape study. A separate
recovery preserves that original source, results, and failed preparation while
continuing on the same logical allocation. No commands are sent to the TPU during
shape execution by the new supervisor.

The local supervisor observes MAIN-12-confirm starting, checks the exact original
controller and independent phase-transport identities, and pauses only the local
controller parent. The independent phase continues and archives itself. Its
inactive/zombie process, complete case count, successful earlier main stages,
sealed result hashes, explicit known-idle remote state, and scoped Git cleanliness
must all pass before takeover. The stopped parent is then retired without running
its pending release. It is recorded as superseded, not normally completed.

A new frozen controller audits the original final confirmation, reports the shape
study, installs the locally tested ensurepip-free isolated CPU tools in the new
cpu-tools-v002 directory, and runs Qwen3-0.6B, Mistral7B-v0.3, and Gemma3-1B in that
order. Original model protocols, revisions, independent qualification gates, and
private token root are unchanged. Preparation is not counted as measurement.
It releases the same allocation after all available model stages and reports
results. No automatic replacement allocation or blind retry is allowed.

A separate local watchdog resumes the original parent after supervisor loss
before the durable takeover fence. After the fence it never resumes that releaser:
it verifies the saved idle evidence and finishes/adopts recovery instead. Ambiguous
launches stop explicitly. Frozen source and each execution remain archived with
scoped commits. A combined live feed retains original failures and results and
shows the queued recovery; it never overwrites the original controller feed.

Local orchestration needs the laptop powered, online, and lid open. Sleep guards
prevent idle sleep. Model execution can still fail qualification or encounter
runtime/download problems; automatic launch is not a promise of scientific success.
